Goyma Conexiones

Aplicación de escritorio para la gestión de un negocio en Cuba.

Qué hace

  • Inventario de productos, con costo, precio y existencias.
  • Ventas, servicios, compras y entregas, con sus facturas.
  • Clientes, proveedores y cuentas por cobrar.
  • Tasas de cambio de las monedas que usa el negocio.

Cómo funciona

Es una aplicación de escritorio para Windows que guarda todos los datos en el propio equipo y funciona sin conexión a internet. No tiene servidor ni comparte los datos del negocio con nadie.

Tasas de cambio

Cuando hay conexión, la aplicación puede consultar la tasa representativa del mercado informal en la API de tasas de elTOQUE, desde su propio programa y como mucho unas pocas veces al día. Las tasas obtenidas se muestran citando a elTOQUE como fuente.
